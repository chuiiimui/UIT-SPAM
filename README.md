# UIT - SPAM

**United Institute Of Technology - Student Project Assessment And Mentorship**

College final-year project submission, mentoring & assessment portal.

## Stack

- **Next.js 16** (App Router) + **TypeScript**
- **Prisma** + **SQLite** (swap `DATABASE_URL` to PostgreSQL for production)
- **Auth.js** (NextAuth v5) credential logins per role
- **Tailwind CSS v4** with UIT brand theme

## Quick start

```bash
npm install
npm run db:reset
npm run dev
```

Open http://localhost:3000
